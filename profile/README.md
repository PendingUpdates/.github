# PendingUpdates

**[Open the Response Menu](https://github.com/PendingUpdates/Response-Menu)** for incident response and security audit tools.<br>
**[Visit PendingUpdates.com](https://pendingupdates.com/)** for vulnerability records and vendor patch guidance.

## At the counter

If a mailbox looks compromised, start with **BEC** to trace email and account activity. If you have Windows event logs, **CrumbTrail** turns them into a timeline. For a Microsoft 365 security review, pick **Flapjacks**. For an on-premises Active Directory Group Policy audit, use **[GPO Grits](https://github.com/PendingUpdates/GPO-Grits)** to review exported policies offline. [Browse the tool workflows](https://github.com/PendingUpdates/Response-Menu/blob/main/docs/tool-workflows.md).

## At the terminal

Look up a CVE by ID or product to find affected versions and source references. The CISA filter shows vulnerabilities with documented exploitation in the wild. [Search the CVE archive](https://pendingupdates.com/archive.php) · [Browse known exploited vulnerabilities](https://pendingupdates.com/archive.php?kev=1)
